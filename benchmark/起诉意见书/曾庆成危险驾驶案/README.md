# 曾庆成危险驾驶案

本案基于清远市公安局清新分局出具的起诉意见书，涉及危险驾驶罪（醉酒驾驶）。

## 案件摘要

2023年06月15日00时许，犯罪嫌疑人曾庆成饮酒后驾驶悬挂粤RH0472号牌的普通二轮摩托车，行驶至清远市清新区太和镇府前路与侨苑路交汇处路段时被执勤民警查获。经检测，呼气式酒精测试结果为191mg/100ml，血液乙醇浓度为202mg/100ml，达到醉酒驾驶标准。犯罪嫌疑人到案后如实供述，认罪认罚。
